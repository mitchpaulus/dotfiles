I have a CLI tool 'bm' that keeps all my bookmarks. You can use the '--help' option to see current usage.

A bookmark can have multiple locations, in a priority order.
This is most often useful for me with SharePoint files, where I want the first reference to be to a `file:///` URL,
followed by an actual `https://` URL.
