---
name: 'mmysql'
description: 'mmysql is my personal CLI tool for working with MySQL databases. It is a much better CLI experience than the default MySQL CLI.'
---

`mmysql` is a better CLI for querying, executing, and uploading mass data to MySQL databases. It works JSON first for output and input.
Authentication is simplified. Updating gets easier as well, with simple methods to match the appropriate records.

Check the live help through '--help' flag for more.
