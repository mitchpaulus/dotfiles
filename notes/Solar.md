# Solar Calculations

```
n = day of year (Jan 1 = 1)
```

```
Esc = solar constant 433.3 BTU/h ft2
Eo = Esc * (1 + 0.033 cos(360 deg * (n -3) / 365))
```

Useful metric for annual kWh is specific PV power output in kWh/kWp where kWp is peak DC kW from standard 1000 W/m2 conditions.

This is usually between 1,000 and 2,000. Coppell is 1617.7 from global solar atlas.
